# Delhi Public School media library

Licensed stills and a demo campus film used by the frontend. Swap any file in place — paths stay the same.

```
assets/
  campuses/   one hero + gallery still per Delhi-NCR campus
  sections/   unique banner for each app module
  videos/     demo campus tour (not an official DPS film)
  3d/         local SVG ornaments
  icons/      brand marks
```

Sources: Unsplash (images) and Pexels (tour video). All stored locally for offline/dev use.
The virtual-tour player always labels the clip as **demo / licensed**, never as official DPS footage.
